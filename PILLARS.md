# Innehållspelare – en per veckodag

Dagens pelare styrs av veckodagen (svensk tid). Hitta en ny vinkel inom pelaren varje gång. Se LOG.md.

| Dag | Pelare | Vad inlägget gör | Föreslagna bildtyper |
|---|---|---|---|
| Måndag | Risken | Gör problemet konkret: kunder frågar AI, och den som inte nämns finns inte i svaret. | cover → text → text → cta |
| Tisdag | Så fungerar AI-svar | Förklarar konceptuellt hur AI-assistenter formar svar och var de hämtar information. Inga siffror. | cover → text(steps) → text → cta |
| Onsdag | Vad vi mäter | Daglig mätning i de fem motorerna. Varför mätning över tid slår enstaka stickprov. | cover → text(pills) → text → cta |
| Torsdag | Vad vi gör | Ett av de tre spåren på djupet (rotera: innehåll, tredjepartsnärvaro, mätning). | cover → text(rows) → text → cta |
| Fredag | Myt eller verklighet | Bemöter en vanlig missuppfattning, t.ex. ”SEO räcker”, ”AI hittar oss automatiskt” eller ”det här gäller bara e-handel”. | cover → text → text → cta |
| Lördag | Testa själv | Ger en fråga företaget kan ställa i ChatGPT om sin egen bransch, och vad de ska titta efter i svaret. | cover → text(steps) → cta |
| Söndag | Tanke | Ett kort, eget påstående från Mynth om AI-synlighet. | quote → text → cta |
